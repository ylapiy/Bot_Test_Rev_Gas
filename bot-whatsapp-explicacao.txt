BOT DE WHATSAPP EM PYTHON - EXPLICAÇÃO
======================================

O bot está pronto no arquivo whatsapp-bot.zip. Ele foi testado simulando as
mensagens que a Meta envia, e faz tudo isto:

- Valida o webhook quando você cadastra a URL.
- Recusa requisições que não vêm da Meta (confere a assinatura com o APP_SECRET).
- Responde "oi" com um menu de 3 botões e reage ao clique em cada botão.
- Não responde duas vezes quando a Meta reenvia a mesma mensagem.
- Marca as mensagens como lidas e responde áudio ou imagem com uma mensagem padrão.


MUDANÇA EM RELAÇÃO AO GUIA ORIGINAL
-----------------------------------
Não foi usada a biblioteca python-whatsapp-bot. Ela é de terceiros, então a
forma de usar pode mudar sem aviso. O código fala direto com a API oficial da
Meta (WhatsApp Cloud API, Graph API v26.0), usando só requests e Flask.


CAMINHO MAIS RÁPIDO PARA COLOCAR NO AR (cerca de 30 min)
--------------------------------------------------------
1. No developers.facebook.com, crie um app do tipo Empresa e adicione o
   WhatsApp. Copie o token e o ID do número para o arquivo .env.

2. Ainda no painel, cadastre o seu celular no campo "Para". No modo de teste,
   o bot só manda mensagem para números cadastrados ali.

3. No computador, rode:

     pip install -r requirements.txt
     python app.py
     ngrok http 5000

4. Cadastre https://SUA-URL.ngrok-free.app/webhook como webhook no painel e
   ASSINE O CAMPO "messages". Muita gente esquece essa parte, e aí nenhuma
   mensagem chega.

Para personalizar o bot, edite só o bot.py: ali ficam os botões, as respostas
e as palavras-chave.


TRÊS REGRAS DA META PARA CONHECER ANTES DE COMEÇAR
--------------------------------------------------
1. Janela de 24 horas: o bot só pode mandar mensagem livre até 24 horas depois
   da última mensagem do cliente. Para começar uma conversa, ou passado esse
   prazo, é preciso um modelo de mensagem (template) aprovado pela Meta.
   A função send_template já está pronta no código.

2. Token: o token temporário expira em 24 horas. Para usar de verdade, gere um
   token permanente (o README do projeto explica como).

3. IA de uso geral: desde 15 de janeiro de 2026, a Meta proíbe chatbots de IA
   de uso geral na API do WhatsApp Business (algo como um "ChatGPT no
   WhatsApp"). Empresas que usam IA no atendimento ao cliente pelo WhatsApp
   não são afetadas.


PRÓXIMO PASSO
-------------
Se você disser o que o bot precisa fazer (agendamento, pedidos, perguntas
frequentes etc.), o bot.py pode ser adaptado para o seu caso.
